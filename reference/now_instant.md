# The current time

Temporal's `Temporal.Now.instant()`: the system clock as an
[`instant()`](https://pedrobtz.github.io/zutempo/reference/instant.md),
at the precision the platform's clock offers.

## Usage

``` r
now_instant()
```

## Value

An
[`instant()`](https://pedrobtz.github.io/zutempo/reference/instant.md)
of length one.

## Examples

``` r
now_instant()
#> <zutempo_instant[1]>
#> [1] 2026-10-15T11:17:22.646510601Z
```
